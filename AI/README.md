This directory contains the complete knowledge base required for any AI software engineer to contribute to the SahakarERP project.

- What the project is
- Why it exists
- How it is built
- Coding standards
- Business rules
- Development workflow
- Future roadmap

without requiring the project owner to repeatedly explain the project.

# Repository Philosophy

SahakarERP is not simply an accounting package.

The objective is to build a complete ERP platform for Labour Cooperative Societies operating in Maharashtra.

The application should eventually manage

- Society Administration

- Members

- Directors

- Meetings

- Resolutions

- Tender Management

- Work Orders

- Execution Agencies

- Suppliers

- Accounting

- GST

- Compliance

- Government Bills

- Documents

- Letter Generation

- Certificate Generation

- Reports

- Dashboards

- Analytics

- Mobile Integration

Every module must contribute towards this long-term vision.

---

# AI Responsibilities

Every AI agent contributing to this repository should

Understand the architecture before changing code.

Prefer incremental improvements over rewrites.

Reuse existing modules.

Maintain backward compatibility whenever possible.

Avoid duplicated business logic.

Never introduce placeholder code.

Produce production-ready code.

Respect the existing coding standards.

Keep commits focused and meaningful.

---

# Human Responsibilities

The project owner is responsible for

Approving architectural changes.

Testing generated code.

Managing deployments.

Reviewing commits.

Maintaining production data.

---

# Development Principle

Every sprint must produce a working application.

Every completed feature must be

Implemented

Reviewed

Committed

Pushed

Deployed

Verified

The repository should remain deployable at every stage of development.

---

# Long-Term Goal

The final objective is to create the most comprehensive ERP available for Labour Cooperative Societies in Maharashtra.

The application should reduce paperwork, improve transparency, simplify statutory compliance, and digitize the complete lifecycle of cooperative society operations.
